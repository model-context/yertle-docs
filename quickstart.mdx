This guide walks you through authenticating, listing your organizations, and reading a node from the Yertle API.

## 1. Get an account

Sign up at [yertle.com](https://yertle.com) and create or join an organization.

## 2. Generate a Personal Access Token

Sign in to [yertle.com](https://yertle.com), open your [settings page](https://yertle.com/settings), and under **Personal Access Tokens** click **Create token**. Give it a descriptive name (e.g. "quickstart laptop") and copy the token — it starts with `yrt_` and you'll only see it once.

Export it:

```bash
export YERTLE_TOKEN="yrt_..."
```

For alternatives (Yertle CLI wrapper, Cognito browser session), see the [Authentication guide](/authentication).

## 3. Make your first API call

List the organizations you belong to:

```bash
curl https://api.yertle.com/orgs \
  -H "Authorization: Bearer $YERTLE_TOKEN"
```

You should see a JSON response with your orgs:

```json
{
  "organizations": [
    {
      "id": "ed411977-...",
      "name": "Acme Inc.",
      "role": "owner"
    }
  ]
}
```

## 4. Read a node

Pick an org ID and a node ID from your workspace, then fetch the complete state:

```bash
curl https://api.yertle.com/orgs/{org_id}/nodes/{node_id}/tree/main/complete \
  -H "Authorization: Bearer $YERTLE_TOKEN"
```

This returns the full node with parents, children, connections, tags, directories, and visual properties.

## Prefer Python?

Install the SDK into your project — same three-line quickstart in code:

```bash
uv add yertle
```

`uv add` works inside a uv project; run `uv init` first if you don't have one.

```python
import yertle

yertle.configure(token="yrt_...")
for org in yertle.orgs.list():
    print(org.name)
```
